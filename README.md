# Code for Your Community

Promotional website for LMC 3403, Group 4 (Emilee Tran, Erik Larson, Hebe Huang, Joseph Shen).
It covers the nonprofit technology gap, Hack4Impact, Bits of Good and Epic Intentions, tied to UN SDG 11 and Georgia Tech's Sustainability Next plan.

**Live site:** https://eriklarson12.github.io/code-for-your-community/

This is a student class project. It is not affiliated with Bits of Good, Hack4Impact or Epic Intentions.

## Editing

The site lives in `src/`. See [`src/README.md`](src/README.md) for where each section's text goes and how to preview it.

Every push to `main` redeploys the live site in about a minute.
